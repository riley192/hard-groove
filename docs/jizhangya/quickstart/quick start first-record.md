# 快速上手

### 第一次记账：从安装到记下第一笔（教程）
记账鸭是一款用于记录个人支出的软件。记录过程简单，输入金额并选择类别即可快速记录支出。下面来教大家如何使用记账鸭进行一笔记账。
#### 安装
记账鸭支持 iOS 和 Android 双平台。我们根据自己的手机系统选择对应的版本进行安装，链接如下：
iOS 平台安装链接：www.jizhangyaios.com（iOS 13及以上）
Android 平台安装链接：www.jizhangyaand.com（Android 5.0及以上）
#### 记下第一笔
安装完成后我们打开软件，进行第一笔记录。
1. 点击右下角"＋"号，弹出记录界面
2. 在金额栏输入金额
3. 选择分类（餐饮、交通等）
4. 点击保存，首页出现一条记账信息
这样我们就完成了一笔记录。
#### 常见问题
1. 我在金额栏输入了“二十”，为什么记录失败了？
答：金额栏只支持数字输入，如：20、3.5、5000。不支持汉字输入。使用数字重新输入可正常记录。
2. 可以自定义分类吗？
答：可以的，选择分类时选中“自定义”，在支出分类中输入需要的选项，保存后按正常分类进行统计。
