## 第 7 题：概念解释（你还没写过的体裁）

题目：**给一位运营同事解释"什么是 API"**，300 字以内。

要求：必须用一个生活类比；不追求定义精确，追求"读完能听懂开发说'这个要调 API'是什么意思"。这是 Diátaxis 四类里你唯一没亲手写过的。

API全称为应用程序编程接口，是一组为不同软件组件之间交互而创建的定义和协议。
举个例子，你到银行进行取钱这个操作，就是调用了银行的 API。银行有多种业务和大量的金钱，他提供取钱 API，你使用 API办理了其中一项业务，拿到了属于你的那部分钱。于此同时其他业务和钱又是独立与你这个操作之外的，银行定义了取钱这个 API的范围和限制，同时保证了你的正常使用。
在工作中，如果开发说“这个要调 API”，一般意味着有一些需求或者功能可以直接使用其他软件提供的现有功能，或者是这些功能不能直接拿来使用，需要获得对方软件的许可。

改：

我来解释一下什么时 API 。举个例子，你到银行进行取钱这个操作，就是调用了银行的 API。银行有多种业务和大量的金钱，银行提供取钱 API，你使用 API办理了其中一项业务，拿到了属于你的那部分钱。与此同时其他业务和钱又是独立于你这个操作之外的，银行定义了取钱这个 API的范围和限制，同时保证了你的正常使用。

## 第 8 题：排障指南（新体裁）

题目：**《微信语音消息发不出去怎么办》**。

要求：按"症状 → 可能原因 → 对应解法"组织；多个原因按**从最常见到最少见**排序；每个原因配一个"怎么确认是不是它"的验证方法。排障文档的核心不是列答案，是帮读者做排除法。
症状1：说话之后没有显示绿色对话框。
可能原因：操作不当，比如没有在说话时长按输入区按钮。尝试按照正确方法重新发送一次语音消息，发送成功则证明是因为操作不当导致消息发不出去。
对应解法：检查发送语音的操作是否正确。当你已经在聊天界面里，发送语音消息的具体操作是：
1. 按住输入区按钮，同时说话
2. 语音消息说完后，松开输入区按钮
3. 我方显示绿色无内容对话框，语音消息发送成功。

症状2：发送语音消息，我方有绿色对话框生成，但是远离头像端有红色感叹号图标。
可能原因：网络故障，比如没有连接无线局域网或蜂窝网络。尝试重新连接网络，确认网络连接成功后，再次发送消息，发送成功则证明是网络原因导致消息发不出去。
对应解法：检查手机网络连接。进入手机设置，检查手机是否连接了无线局域网或蜂窝网络。如果没有连接或连接失败，尝试重新连接网络。连接成功后再次发送消息。

症状3：发送语音消息，我方有绿色对话框生成，但是远离头像端有红色感叹号图标，并提示对方已经不是你的联系人。
可能原因：对方删除了你。进入对方信息页面，查看是否有添加对方为联系人按钮，如果有则证明是因为对方删除了你所以消息发送失败。
解决方法：重新添加对方为联系人，添加成功后重新发送消息。



## 第 9 题：教程 vs 操作指南（体裁辨析实战）

题目：**把你第 6 题的 Excel 支出指南，改写成一篇教程**——读者设定为"完全没用过 Excel 的人"。

要求：刻意体现教程和操作指南的差异——教程预设零基础、每一步要确认进展（"现在你应该能看到……"）、可以穿插讲"为什么这么做"。改完后用三句话说清：你觉得两种体裁最大的区别是什么。

#### 如何用 Excel 表格统计每月支出（无门槛版）
掌握日常支出的金额和类别可以帮助我们有效理财，记账就是一种直观掌握支出的有效技能。使用 Excel 表格可以方便且清晰的记账，下面就是对应的教程，即使你没有用过 Excel 表格也可以看懂。
##### 准备阶段：
你需要安装 Excel 软件，或者使用网页版 Excel。
Excel下载地址：[下载适用于 Windows 和 Mac 的 Microsoft Office 365 | Microsoft 365](https://www.microsoft.com/zh-cn/microsoft-365/download-office)根据电脑系统下载对应的版本并安装。
网页版 Excel：[Microsoft](https://www.microsoft.com/zh-cn/microsoft-365/excel)
##### 创建用于记账的 Excel 表格：
使用 Excel 统计每月支出的关键在于创建一个包含关键统计信息的表格，具体步骤如下：
1. 打开安装好的软件或者 Excel 网页，进入新建界面。页面上会显示许多模板，在这个教程中我们使用最基础的空白模板即可。
2. 点击空白工作簿，进入表格编辑界面，这个时候最上方会显示”工作簿1“。为了保证编辑过程中信息不丢失，我们先保存文件。点击左上角的软盘图标，在弹出的保存界面输入文件名”记账表格“，选择你的保存位置，点击保存。弹出界面消失，这个时候如果看到最上方原先默认的”工作簿1“变成了”记账表格“，证明保存成功。
3. 保存好文件就可以进行表格编辑了，记账表格是一种简单的表格，只需要编辑几个单元格就可以完成。在编辑界面你会看到一行从 A 开始的字母，和一列从 1 开始的数字，这一行一列中有淡灰色的线组成的表格，每个格子就是一个单元格。我们从第一行单元格左数第一个格子开始编辑。双击这个单元格，单元格中会出现光标，我们在这个格子里输入”支出时间“，点击随意一个单元格，看到刚才编辑的单元格中显示文字”支出时间“，说明这个单元格编辑成功了。以此类推，我们从左往右继续编辑剩下的单元格，分别在这一行右边相邻的两个单元格中输入”支出类别“和”支出金额“。这样我们就完成了记账表格的编辑。
##### 记账表格日常记录：
创建好表格我们就可以开始进行日常的记录了，每天坚持按照类别记录每一笔支出，可以在月底根据需要进行总体或分类的统计，对自己的财务支出全面掌握。
日常记录流程如下：
1. 从左边第一格信息开始，在支出时间列下的第一个空白单元格记录当日日期，格式为**yyyy/mm/dd**，也就是年月日的格式。
2. 光标移动到同一行相邻第二个空白单元格，记录支出类别（比如：餐饮、交通、娱乐等等）
3. 来到向右相邻单元格，记录支出金额数字
4. 我们得到了一行由三个格子组成的支出记录，接下来另起一行当天其他类别支出，直到记录完成。
5. 现在我们有了几行今天的支出记录，每天记录我们会得到更加详细的信息。
注意事项：每条支出记录为一行，每行只记录当天一个类别的一次金额。
##### 记账统计：
坚持记录一段时间后，我们拥有了一份包含日期、类别和金额的表格，当我们想要统计支出结果时，有以下两种方法：
方法一：选中支出金额列看状态栏总和
把鼠标移动到支出金额列上方的字母行，在本教程中即为字母C。鼠标显示为一个黑色实心向下箭头，点击字母C，选中支出金额列。这个时候可以看到支出金额列除首行外全部变成浅灰色，这样的变化代表着这一列全部被选中。保持选中状态时，我们可以在页面最下方看到对于选中区域的统计数据：
- 平均值：选中区域金额总和基于计数数量的平均值
- 计数：选中区域有多少单元格是有内容的（包含首行文字格）
- 求和：所有金额总和
在这个区域的数据就是我们所统计金额的总和。
方法二：使用 SUM 函数统计总支出
选中金额列查看统计金额是很方便的方法，操作步骤较少。但是也有一定的限制，这个总和数据不会保存在单元格中，只有选中时才会出现，如果我们希望可以随时在表格上查看金额，可以使用SUM函数来统计。具体方法如下：
1. 选中一个空白单元格作为显示统计金额的格子，这个格子的位置可以根据你的需要来选择，常见的位置有金额列最下方的空白单元格、另起一列的任意空白单元格等。
2. 在选中单元格中输入SUM统计函数。SUM函数的公式为SUM(number1,number2)，number1和2代表想要统计数据的上下范围。在所”单元格中输入“=SUM(”选择需要统计数据列最上方的格子，可以看见这个格子的外框线变成了彩色的虚线。接着输入一个“,”，就是一个半角逗号，再选中统计数据列最下方的格子，可以看见这个的外框线变成了与上一个格子不同颜色的虚线。回车，单元格中的数据就是我们统计的数据总和。
两种方法可以进行互相验证，来检查统计是否有误。汇总结果与银行/支付宝/微信账单的实际支出总额核对，可进一步验证统计是否准确。
##### 分类筛选
记录数据的时候我们给每一条支出都记录了支出类别，就是为了在复盘统计的时候可以选择性的查看各类支出。设置分类筛选的方法如下：
1. 把鼠标移动到支出类别列上方的字母行，在本教程中即为字母B。鼠标显示为一个黑色实心向下箭头，点击字母B，选中支出类别列。
2. 点击上方工具栏中，编辑区的排序和筛选。在弹出的列表中点击筛选，这个时候我们看到支出金额格格内右侧出现了一个小方形按钮，按钮内有一个倒三角形。
3. 点击按钮，在出现的提示框中可以看到一列全选的列表。取消你不需要的选项，只选中你需要的选项，点击确定。
4. 现在列表中就只有你需要查看的类别的支出金额了。
在分类筛选状态下，可以使用选中支出金额列看状态栏总和来统计分类支出。
##### 总结
现在你掌握了使用 Excel 记录统计每月支出的方法，快去试试吧

## 第 12 题：验证挑战（本期最重要的一题）⚠️

下面这份小抄埋了 **3 处事实错误**。全部找出来，写出正确说法，以及**你的验证方式**（亲手实验或查官方文档，二选一，写出来）：

> 《新手速查》
> 
> 1. Excel：SUM 函数计算总和时，如果选中区域里混有文本格式的数字，函数会报错并中断计算。
>     
> 2. Markdown：表格中的竖线必须严格上下对齐，否则无法渲染成表格。
>     
> 3. 微信：单条语音消息最长可录 60 分钟，适合发送长段语音。
>     

不许猜，每条都必须真的去验证——练的就是"识别一本正经的胡说八道"的手感。
1. 选中区域里混有文本格式的数字，函数不会报错，会自动忽略这个单元格内容不计入统计。
验证：我亲手试验了，在一列统计数字里其中一格写了汉字数字“十一”，不影响统计，当然统计结果也不包含这个“十一”。
2. 表格中的竖线不需要上下对齐也可以渲染成表格。
验证：我亲手实验了，在markdown中只要是使用竖线把内容隔开，不需要上下行对其，会自动根据隔开的数量对其相应单元格。
3. 单条语音消息上限为 60 秒
验证：查看官方文档，文档链接：[微信开放平台介绍](https://developers.weixin.qq.com/doc/)
