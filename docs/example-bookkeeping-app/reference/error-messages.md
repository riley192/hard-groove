
#### 错误信息一览
1. 网络断开时保存失败
错误提示：网络错误，请重新连接后再次保存
解决方法：检查网络连接状态，确认网络重新连接后再次保存。
2. 金额栏输入了文字
错误提示：输入内容只支持纯数字
解决方法：删除金额栏文字，输入正确格式的数字。
3.  导出失败
错误提示：导出失败，请再次尝试
解决方法：清理存储空间，重新进行导出操作。
4. 未登录时尝试同步
错误提示：账号未登录，请登录后再进行同步
解决方法：登录账号后再次进行同步操作。
5.  存储空间不足
错误提示：存储空间不足，请清理手机存储后重试
解决方法：保证手机拥有至少500 MB可用存储空间，以维持软件正常存储数据。
