# 某记账软件

某记账软件（下称“本软件”）是一款用于记录个人支出的软件。
## 功能特性

- 一键记录，输入金额并选择类别即可快速记录支出
- 记账可视化，图表面板页面显示各项支出占比
- UI美观，可爱的元素随处可见
- 定时提醒，可设置定时功能提醒及时记账
- 支持多种导出格式，可根据需要导出CSV、Excel、PDF格式文件


## 安装
本软件支持 iOS 和 Android 双平台。
iOS 平台安装链接：www.example.com（iOS 13及以上）
