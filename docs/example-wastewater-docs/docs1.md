### 一座屠宰废水处理厂是怎么工作的

屠宰废水处理厂的运行主要依靠各处理单元的有序工作，对污水进行逐步处理，最后产出符合要求的出水。

屠宰废水来自于屠宰过程中的各个环节，主要具有以下特点：  

 - 颜色呈红褐色，有难闻的腥臭味
 - 有机物含量高，固体悬浮物含量高
 - 含有大肠菌、粪便链球菌等危害人体健康的致病菌
 - 水质、水量在一天内的变化比较大

屠宰废水在处理流程中依次经过如下处理单元：格栅井、一级提升水池、斜筛网式固液分离机、调节池、浅层气浮机、水解酸化池、多级A/O生化池、二沉池、高密度沉池、消毒池。
处理流程中产生的污泥由污泥浓缩池收集，经污泥脱水系统脱水后处置。
处理流程中产生的废气由生物过滤塔过滤后排放。
下面我把处理流程按照预处理、生化处理和深度处理分为三个部分，分别来讲一下它们是怎么工作的。

1. 预处理

预处理的主要目标是去除水中的大部分的悬浮物和动植物油，减轻后续处理负担。

预处理包括格栅井、一级提升水池、斜筛网式固液分离机、调节池、浅层气浮机这五个处理单元。
污水由总管道进入细格栅，去除掉水中绝大多数的固体悬浮物（毛发、粪便及其他屠宰固体废物）。经细格栅处理后的水自流进一级提升水池，由水池内的水泵运输到斜筛网式固液分离机，斜筛网式固液分离机可以进一步减少水中剩余的悬浮物。

污水经斜筛网式固液分离机处理后，自流进入调节池。屠宰废水具有水质、水量在一天内的变化比较大的特点，调节池的作用就是在水质水量出现较大波动的时候进行调节，把调节池内废水通过水泵稳定持续地提升入后续处理工序，保证处理流程的稳定运行。
水质和水量经过调节池稳定后，通过泵输送至浅层气浮机。浅层气浮机用于去除水中的乳化油和微小悬浮颗粒。

浅层气浮机处理后的污水流入水解酸化池。

至此，经过预处理处理后的污水已经去除了水中大部分的悬浮物和动植物油，可以进入下一阶段进行生化处理。

2. 生化处理

生化处理是整个处理流程中的核心环节，主要目标是去除水中的氨氮、有机物等污染物。

生化处理包括水解酸化池、多级A/O生化池两个处理单元。

经过预处理的废水进入水解酸化池，在这里水中的大分子有机物被水解成为小分子有机物，为下一步多级A/O生化池处理做准备。

经过水解酸化后的污水自流进入多级A/O生化池，多级A/O工艺是一种利用活性污泥进行污水处理的工艺，可以高效处理污水中的氨氮、总氮、磷酸盐等污染物。此时水中的有机物以小分子有机物为主，在这一步中可以被活性污泥中的微生物进行进一步降解，最终转化为活性污泥的一部分。

生化处理完成后的污水呈现出泥水混合物的状态，需要进行深度处理，分离水中的活性污泥和清水。

3. 深度处理

深度处理包括二沉池、高密度沉池、消毒池这三个处理单元。

深度处理的目的是分离污水中的活性污泥。生化处理后，水中的污染物已经基本被转化为活性污泥，在本阶段进行充分的分离后，清水部分就可以达标排放了。

多级A/O生化池处理后的污水通过水泵提升至二沉池。二沉池通过斜板分离泥水，使混合液澄清。
二沉池沉淀过后的上层清水自流至高密度沉池。高密度沉池通过加药搅拌能够进一步去除水中的悬浮物、磷酸盐以及部分COD等污染物。

高密度沉池上层清水自流进入消毒池，在消毒池中进行消毒后达标出水。

污水经处理后同时满足《污水排入城镇下水道水质标准》（GB/T 31962-2015）和《污水综合排放标准》（GB8978）三级排放标准，排入市政污水管网。
