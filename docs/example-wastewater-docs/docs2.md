### 叠螺式污泥脱水机操作规程

本规程用于叠螺式污泥脱水机的日常开机、运行检查与停机操作。不指定设备型号，按通用设备描述，具体参数以厂家手册为准。
#### 1. 开机前准备
- 絮凝混合槽清除杂物
- 过滤本体排空污泥
- 螺旋轴轴头处没有泥块
- PAM制备系统加入絮凝剂粉剂，开启PAM制备系统搅拌装置
#### 2. 开机步骤
1. 开启电源
2. 开启手动喷淋装置，喷淋过滤本体上的动定碟片
3. 手动喷淋动定碟片2分钟
4. 保持手动喷淋，开启本体驱动电机
5. 检查本体驱动电机的旋转方向是否与机体标识箭头一致
6. 继续喷淋动定碟片2分钟
7. 依次启动絮凝剂供药泵、进泥泵及絮凝搅拌电机
8. 根据处理量和含水率要求，调整进泥量和螺旋轴转速度、调整背压板间距
9. 关闭手动喷淋装置。
10. 开机步骤完毕

#### 3. 开机后检查

叠螺式污泥脱水机开机运行时需要检查：

- 螺旋轴旋转是否正常
- 混合槽泥位是否稳定
- 各转动部件运行是否正常
- 有无异响，运行中出现异响或堵料，立即停机
#### 4. 停机步骤
1. 关闭进泥泵，停止进污泥
2. 关闭絮凝剂供药泵、PAM制备系统，停止加药
3. 放空絮凝混合槽，关闭絮凝搅拌电机
4. 待污泥全部排尽（不得少于30分钟），手动喷淋过滤本体5分钟，将设备冲洗干净
5. 关闭电源。
