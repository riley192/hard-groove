### 出水水质异常排查表

| 异常表现  | 原因分析                                                                      | 解决方法                                                                                                 |
| ----- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| COD超标 | 引发水质异常的原因通常涉及进水、工艺和设备三个层面，COD 主要由生化处理单元进行处理，所以在工艺设备方面优先检查水解酸化池和多级A/O池部分。  | 首先复测进水COD，确认是否异常，其次检查多级A/O池的溶解氧、水解酸化池的 pH 值和污泥浓度，最后排查曝气设备是否堵塞或加药系统是否失效。根据检查结果定位，采取调节水质、调整曝气或维修设备等措施。 |
| 氨氮超标  | 引发氨氮超标的原因通常涉及进水、工艺和设备、温度四个层面，氨氮主要由生化处理单元进行处理，所以在工艺设备方面优先检查水解酸化池和多级A/O池部分。 | 首先复测进水氨氮，确认是否异常，其次检查多级A/O池的溶解氧、水解酸化池的 pH 值和污泥浓度，排查曝气设备是否堵塞，检测水温是否低于15℃。根据检查结果定位，采取调节水质、调整曝气或维修设备等措施。 |
| SS超标  | 常见原因包括沉淀池表面负荷过高、絮凝剂投加量不足或选型不当、刮泥机故障导致污泥上浮，以及预处理段过滤单元故障。                   | 需逐一检查混凝效果、沉淀状态及预处理段过滤设备运行情况。                                                                         |
