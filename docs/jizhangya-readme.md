# 记账鸭

记账鸭是一款用于记录个人支出的软件。

Bookkeeping Duck is an app designed to help you keep track of your personal expenses.
## 功能特性
- 一键记录，输入金额并选择类别即可快速记录支出。
- 记账可视化，图表面板页面显示各项支出占比
- UI美观，可爱的鸭子元素随处可见
- 定时提醒，可设置定时功能提醒及时记账
- 支持多种导出格式，可根据需要导出CSV、Excel、PDF格式文件

- One-tap recording: enter an amount, pick a category, done

- See where your money goes: a dashboard page displays the percentage breakdown of each expenditure category.

- Attractive UI: cute duck motifs feature throughout the app.

- Scheduled reminders: set reminders to ensure you record your expenses promptly.

- Supports multiple export formats: export files in CSV, Excel or PDF formats as required.

## 快速上手
1. 点击右下角"＋"号，弹出记录界面
2. 在金额栏输入金额
3. 选择分类(餐饮、交通等)
4. 点击保存，首页出现一条记账信息。
## 常见问题
同步失败怎么办？  
记账鸭默认自动同步，频率为每小时自动同步一次。自动同步失败时可选择手动同步，进入“我的”页面，点击顶部的“立即同步”按钮。
换手机数据还在吗？  
记账鸭支持登录账号以保留信息，换手机后登录同一账号会同步全部数据。
